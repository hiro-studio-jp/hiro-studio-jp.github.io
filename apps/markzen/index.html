Features

📁

フォルダ管理

Folder Management

SAFを使ったフォルダ・ファイルのツリー表示。複数選択・移動・一括ゴミ箱も対応。

File and folder tree view utilizing SAF. Supports multi-select, move, and bulk trash operations.

✏️

Markdownエディタ

Markdown Editor

リアルタイムプレビュー付きのフル機能エディタ。GFM（表・取り消し線）に対応。

Full-featured editor with real-time preview. Fully supports GFM including tables and strikethroughs.

🔍

全文検索

Full-Text Search

ファイル内容を横断した高速全文検索。マッチ箇所のハイライト表示付き。

Lightning-fast full-text search across all files with matched syntax highlighting.

📄

PDF書き出し

PDF Export

Markdownをそのままスタイル付きPDFとして複数ページで書き出し。

Export your Markdown directly into fully-styled, multi-page PDF documents.

🕒

編集履歴

Edit History

ファイルごとに編集履歴を自動保存。過去バージョンへの復元が可能。

Automatically saves edit history per file. Easily restore to previous versions at any time.

🗑️

ゴミ箱機能

Trash Feature

削除ファイルはゴミ箱に保管。元のパスへの完全復元に対応。

Deleted files are kept safely in the trash and can be perfectly restored to their original paths.

🌙

ダーク/ライトモード

Dark/Light Mode

システム設定に追従する自動テーマ切り替え。フォントサイズも調整可能。

Automatic theme switching that securely follows your system settings. Font sizes are fully adjustable.

🌐

日本語・英語対応

Bilingual Support

システム言語に応じてUIを自動切り替え。

UI seamlessly switches languages based on your device's system settings.

About

MarkZenは、Androidのストレージ（SAF）を直接使ってMarkdownファイルを管理・編集できるエディタです。クラウド同期を使わず、自分のフォルダにファイルを置いて使いたい方に最適です。

MarkZen is a Markdown editor for Android that lets you manage and edit files directly in your local storage via SAF. Perfect for users who prefer working with their own files without cloud sync.
